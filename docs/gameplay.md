Физические параметры:

* Масса игрока - 10
* Gravity Scale - 0 (гравитация прописана не через Rigidbody)
* Физические материалы не используются

Префабы:

* CharacterPlatformer - игрок
* Grass - трава для локации
* Lever - рычаг для взаимодействия (использует скрипт Lever и box collider 2d с параметром is trigger для работы)
* TreeBackground - деревья для фона

UI:

UI не используется, на сцене даже нет canvas

Возможность изменения параметров:

* Можно поменять характеристики персонажа (изменить скорость, силу прыжка и инерцию)
* Можно поменять положение блоков на уровне
