Документация по сборке проекта (DevOps)

Настройки сборки (Build Profiles)
Целевая платформа: Windows (Активный профиль сборки, архитектура Intel 64-bit).
Доступные платформы в Unity 6: macOS, Linux, Android, iOS, WebGL, Universal Windows Platform и др.
Включенные сцены: `IndieMarc/PlatformerDemo/PlatformerDemo` (Шаблон TopDownDemo был успешно удален/исключен из сборки).

 Установленные пакеты (Package Manager)
В проекте используются следующие ключевые пакеты для 2D-игры:
 2D Animation
 2D Sprite
 2D Tilemap Editor
 Input System
 Unity Version Control

 Структура папок проекта
В корневой директории `Assets` присутствуют:
 `IndieMarc/` — основные ассеты выбранного шаблона платформера (скрипты, префабы, спрайты).
 `Scenes/` — игровые сцены(1 пустая сцена).
 `Settings/` — конфигурационные файлы проекта и графики.
 `Welcome/` — приветственные материалы ассета.

 Размер проекта
Размер папки проекта: 3.47 ГБ (содержит 69 441 файл).
